Here's the implementation:

```cpp
#pragma once
#include <cmath>

void kernel_durbin(double r[40], double y[40]) {
    double z[40];
    double alpha;
    double beta;
    double sum;
    
    y[0] = -r[0];
    double prev_alpha = -r[0];
    
    for (int k = 1; k < 40; k++) {
        beta = 1.0;
        sum = 0.0;
        
        for (int i = 0; i < k; i++) {
            beta = (1 - prev_alpha * prev_alpha) * beta;
            sum += r[k - i - 1] * y[i];
        }
        
        alpha = - (r[k] + sum) / beta;
        
        for (int i = 0; i < k; i++) {
            z[i] = y[i] + alpha * y[k - i - 1];
        }
        
        for (int i = 0; i < k; i++) {
            y[i] = z[i];
        }
        
        y[k] = alpha;
        prev_alpha = alpha;
    }
}
```

### Explanation:
1. We initialize a temporary array `z` and variables for the algorithm (`alpha`, `beta`, `sum`).
2. The first element of `y` is set to `-r[0]` as the base case.
3. For each subsequent element (k from 1 to 39):
   - Compute `beta` and `sum` terms
   - Calculate the new `alpha` value
   - Update the `y` values using the temporary `z` array
   - Store the new `alpha` in `y[k]`
4. The algorithm recursively builds the solution vector `y` that satisfies the equation Ty = -r.
