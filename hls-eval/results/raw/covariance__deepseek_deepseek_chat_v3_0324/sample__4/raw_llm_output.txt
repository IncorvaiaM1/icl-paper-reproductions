```cpp
#include "covariance.h"
#include <cmath>

void kernel_covariance(double float_n, double data[32][28], double cov[28][28], double mean[28]) {
    const int N = 32;
    const int M = 28;
    const double inv_n = 1.0 / float_n;
    const double inv_n_minus_1 = 1.0 / (float_n - 1.0);

    // Compute the mean of each attribute
    for (int j = 0; j < M; j++) {
        mean[j] = 0.0;
        for (int i = 0; i < N; i++) {
            mean[j] += data[i][j];
        }
        mean[j] = mean[j] * inv_n;
    }

    // Center the data (subtract the mean from each data point)
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            data[i][j] -= mean[j];
        }
    }

    // Compute the covariance matrix
    for (int j1 = 0; j1 < M; j1++) {
        for (int j2 = j1; j2 < M; j2++) {
            double sum = 0.0;
            for (int i = 0; i < N; i++) {
                sum += data[i][j1] * data[i][j2];
            }
            cov[j1][j2] = sum * inv_n_minus_1;
            // The matrix is symmetric
            if (j1 != j2) {
                cov[j2][j1] = cov[j1][j2];
            }
        }
    }
}
```

### Explanation:

1. **Mean Calculation**:
   - First, we compute the mean of each attribute (column) by summing all values in the column and dividing by the number of data points (N).

2. **Data Centering**:
   - We then center the data by subtracting the mean of each attribute from its corresponding values. This step is equivalent to computing the deviations from the mean.

3. **Covariance Calculation**:
   - We compute the covariance matrix by:
     - For each pair of attributes (j1, j2), we calculate the sum of products of their centered values
     - Divide this sum by N-1 to get the sample covariance
     - Store the result in the symmetric matrix (since cov(j1,j2) = cov(j2,j1))

4. **Optimizations**:
   - We precompute the inverse of N and (N-1) to avoid repeated divisions
   - We only compute the upper triangular part of the covariance matrix and mirror it to the lower triangular part since the matrix is symmetric
   - The data centering is done in-place to save memory
