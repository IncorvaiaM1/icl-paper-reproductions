```c
#include "runs.h"

void Runs(int *res_S, int *res_V, int epsilon[N]) {
    // Initialize counters
    int count_S = 0;
    int count_V = 0;
    
    // Handle empty array case
    if (N == 0) {
        *res_S = 0;
        *res_V = 0;
        return;
    }
    
    // Count the first element
    count_S = epsilon[0];
    count_V = 1; // At least one run (the first element)
    
    // Iterate through the rest of the array
    for (int i = 1; i < N; i++) {
        // Count ones
        if (epsilon[i] == 1) {
            count_S++;
        }
        
        // Count runs (when current element is different from previous)
        if (epsilon[i] != epsilon[i-1]) {
            count_V++;
        }
    }
    
    // Store the results
    *res_S = count_S;
    *res_V = count_V;
}
```

### Explanation:

1. **Initialization**: We initialize two counters:
   - `count_S` for counting the number of 1s
   - `count_V` for counting the number of runs

2. **Edge Case Handling**: If the array is empty (though N is defined as 65535, it's good practice), we return 0 for both counts.

3. **First Element Handling**:
   - We initialize `count_S` with the first element's value (0 or 1)
   - We start `count_V` at 1 since the first element is always a run by itself

4. **Array Traversal**:
   - For each subsequent element:
     - If the element is 1, we increment `count_S`
     - If the element is different from the previous one, we increment `count_V` (indicating a new run)

5. **Result Storage**: Finally, we store the counts in the output parameters.

The implementation correctly handles all cases, including:
- All 0s or all 1s in the array
- Alternating 0s and 1s
- Any arbitrary pattern of 0s and 1s

The time complexity is O(N) where N is 65535, as we only traverse the array once. The space complexity is O(1) as we only use a few variables for counting.
