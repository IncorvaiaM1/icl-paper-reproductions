#include "runs.h"

void Runs(int *res_S, int *res_V, int epsilon[N]) {

    int count_S = 0;  // Count of 1s
    int count_V = 0;  // Count of runs
    
    // Initialize with the first element
    if (N > 0) {
        count_S = epsilon[0];
        count_V = 1;
        
        // Iterate through the rest of the array
        for (int i = 1; i < N; i++) {
            // Count 1s
            if (epsilon[i] == 1) {
                count_S++;
            }
            
            // Count runs (transitions between 0 and 1)
            if (epsilon[i] != epsilon[i-1]) {
                count_V++;
            }
        }
    }
    
    // Store the results
    *res_S = count_S;
    *res_V = count_V;
}

   - `count_V` for counting the number of runs

2. **Edge Case Handling**: If the array has at least one element (N > 0):
   - Initialize `count_S` with the first element's value (0 or 1)
   - Initialize `count_V` to 1 (the first element is always the start of a run)

3. **Array Traversal**:
   - For counting 1s (`S`): Simply increment `count_S` whenever we encounter a 1
   - For counting runs (`V`): Increment `count_V` whenever the current element differs from the previous one

4. **Result Storage**: Store the final counts in the output parameters `res_S` and `res_V`
