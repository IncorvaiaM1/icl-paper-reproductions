# Sparse Matrix-Vector Multiplication (SpMV) Kernel Implementation

## File: spmv_crs.h

```cpp
#include <stdint.h>

// Define the floating point type and matrix parameters
typedef double TYPE;
#define N 1000  // Size of the matrix (N x N)
#define NNZ 5000  // Number of non-zero elements

// Top-Level Function: spmv
void spmv(TYPE val[NNZ], int32_t cols[NNZ], int32_t rowDelimiters[N + 1], 
          TYPE vec[N], TYPE out[N]) {
    int i, j, tmp_begin, tmp_end;
    for (i = 0; i < N; i++) {
        out[i] = 0;
        tmp_begin = rowDelimiters[i];
        tmp_end = rowDelimiters[i+1];
        for (j = 0; j < tmp_end - tmp_begin; j++) {
            out[i] += val[tmp_begin + j] * vec[cols[tmp_begin + j]];
        }
    }
}
```

## File: spmv_crs_tb.cpp

```cpp
#include <assert.h>
#include <fcntl.h>
#include <inttypes.h>
#include <stdarg.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/stat.h>
#include <unistd.h>
#include "spmv_crs.h"

int main() {
    // Test case setup
    struct bench_args_t {
        TYPE val[NNZ];
        int32_t cols[NNZ];
        int32_t rowDelimiters[N + 1];
        TYPE vec[N];
        TYPE out[N];
    } data;

    // Initialize sparse matrix in CRS format
    // For this test, we'll create a simple diagonal matrix
    for (int i = 0; i < N; i++) {
        data.vec[i] = 1.0;  // Input vector with all 1s
        data.rowDelimiters[i] = i;
        data.cols[i] = i;
        data.val[i] = 1.0;  // Diagonal matrix
    }
    data.rowDelimiters[N] = N;

    // Expected output (for diagonal matrix with 1s and input vector of 1s)
    for (int i = 0; i < N; i++) {
        data.out[i] = 0.0;  // Will be 1.0 after spmv
    }

    // Call the kernel
    spmv(data.val, data.cols, data.rowDelimiters, data.vec, data.out);

    // Verify results (for diagonal matrix)
    for (int i = 0; 1) {
        assert(data.out[i] == 1.0);
    }

    printf("Test passed!\n");
    return 0;
}
```

### Key Points:

1. The implementation uses Compressed Row Storage (CRS) format for sparse matrices
2. The spmv function:
   - Takes advantage of the sparse structure to only process non-zero elements
   - Uses two nested loops (spmv_1 and spmv_2 as described)
   - Computes the dot product of each row with the input vector

3. The test case:
   - Creates a simple diagonal matrix
   - Uses an input vector of all 1s
   - Verifies the output (which should be 1s for a diagonal matrix)

4. The implementation is optimized for sparse matrices where NNZ << N², providing significant performance benefits over dense matrix-vector multiplication.
