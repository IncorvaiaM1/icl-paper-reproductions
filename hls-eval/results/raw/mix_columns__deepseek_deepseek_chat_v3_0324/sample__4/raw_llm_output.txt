Here's the implementation:

```c
#include "mix_cols.h"

static uint8_t xtime(uint8_t x) {
    return (x << 1) ^ ((x >> 7) * 0x1b);
}

void MixColumns(state_t *state) {
    uint8_t i;
    uint8_t Tmp, Tm, t;
    
    for (i = 0; i < 4; i++) {
        t = (*state)[0][i];
        Tmp = (*state)[0][i] ^ (*state)[1][i] ^ (*state)[2][i] ^ (*state)[3][i];
        Tm = (*state)[0][i] ^ (*state)[1][i]; Tm = xtime(Tm);
        (*state)[0][i] ^= Tm ^ Tmp;
        Tm = (*state)[1][i] ^ (*state)[2][i]; Tm = xtime(Tm);
        (*state)[1][i] ^= Tm ^ Tmp;
        Tm = (*state)[2][i] ^ (*state)[3][i]; Tm = xtime(Tm);
        (*state)[2][i] ^= Tm ^ Tmp;
        Tm = (*state)[3][i] ^ t; Tm = xtime(Tm);
        (*state)[3][i] ^= Tm ^ Tmp;
    }
}
```

This implementation:

1. First defines the `xtime` helper function that performs the Galois Field multiplication by x (0x02) modulo the irreducible polynomial x⁸ + x⁴ + x³ + x + 1 (0x1b)

2. Implements the MixColumns operation which:
   - Processes each column of the state matrix (4 columns total)
   - For each column, it:
     - Calculates a temporary value Tmp that is the XOR of all 4 bytes in the column
     - For each byte in the column, it:
       - Calculates a temporary value Tm that is the XOR of the current byte and the next byte
       - Applies xtime to Tm
       - Updates the current byte using Tm and Tmp
     - The operation ensures proper diffusion across the column

The function modifies the state matrix in-place as required. The implementation follows the AES specification for the MixColumns operation during encryption (the inverse MixColumns operation for decryption would be different).
