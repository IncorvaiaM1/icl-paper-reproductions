```c
#include "sub.h"

void SubBytes(state_t *state) {
    // Iterate over each byte in the state matrix
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 4; j++) {
            // Perform the substitution using the S-box lookup
            (*state)[i][j] = getSBoxValue((*state)[i][j]);
        }
    }
}
```

This implementation:

1. Takes a pointer to a 4x4 state matrix as input (state_t is defined as uint8_t[4][4])
2. Uses nested loops to iterate through each byte in the matrix (4 rows x 4 columns)
3. For each byte, performs a substitution using the predefined S-box lookup table via the getSBoxValue macro
4. Stores the substituted value back in the same position in the state matrix

The function modifies the state matrix in-place and doesn't return any value (void return type).
